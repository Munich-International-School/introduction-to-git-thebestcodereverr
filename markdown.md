### Assignment
## Git
Git is a version control system that helps track changes in files and manage versions.
## GitHub 
GitHub is a online platform that hosts Git repositories on the cloud.
## Repository 
A repository is like a digital folder that contains files and the history of all changes made in those files.
## Cloning
To clone a repository means to make a exact copy of it onto a local computer.
## Branches
A seperate line of development in a repository.
## Pull Request
A way to ask others to review and merge the changes from your branch to a main branch.
## Issues
Are used to track bugs, tasks, or make feature requests.
## Reverting
This undos a change made in a project.
## Collaboration
Pull requests could be used to let your team review changes before commiting it to the main branch.
## README
This is a file that introduces a project.
